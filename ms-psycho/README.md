# ms-psycho – MS Konsylium Psychologiczne (brat bliźniak MS Konsylium)

Osobna aplikacja testowa: **Rozmowa** z jednym terapeutą AI (za nim zespół agentów różnych podejść) i **Pokój psychologiczny** (konsylium terapeutów). Nie zmienia MS Konsylium (medycyny); korzysta tylko z jego modułu wywiadu (`narzedzia/wywiad`) przy budowie.

- Start i obsługa: `START-TUTAJ.md`
- Reguły zespołu: `CLAUDE.md`; agenci: `.claude/agents/`
- Rozmowa: `docs/ROZMOWA.md`, `skrypty/rozmowa.py`; bezpieczeństwo: `docs/BEZPIECZENSTWO.md`, `config/`
- Koncepcja: `docs/KONCEPCJA.md`, sieć agentów: `docs/SIEC-AGENTOW.md`
- Aplikacja: `aplikacja/` (powloka = Electron, rozmowa, pokoj-psychologiczny, prezent – tylko wersja 1)

Autorzy wkładów (wątki projektu, 1.11.2026): Psycholog (aplikacja, scalenie), Merytoryczny (role, bezpieczeństwo, źródła), Innowacyjny (sieć agentów, próba na sucho PSY‑03), Graficzny (scena Pokoju, prezent, makieta Rozmowy), Testowy (przypadki PSY‑01…10).
